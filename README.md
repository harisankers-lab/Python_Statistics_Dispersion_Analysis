# Statistical Dispersion Analysis – Python Case Study

## Overview
This repository contains a Python case study on **Statistical Dispersion**, exploring how data values are spread around their mean. The notebook uses practical examples to understand variability and compare consistency between different datasets.

## Topics Covered
- Mean and Range
- Variance calculation (step-by-step)
- Variance using NumPy
- Standard Deviation
- Comparing Data Consistency
- Creating Functions for Statistical Reports
- Population vs Sample Variance
- Data Grouping and Aggregation using Pandas
- Effect of Outliers on Data Dispersion

## Technologies Used
- Python
- NumPy
- Pandas
- Google Colab / Jupyter Notebook

## Dataset
The case study uses sample datasets representing two classes with different mark distributions and a table containing marks from two sections.

## Key Learnings
- Understanding how dispersion measures describe data variability.
- Comparing datasets using variance and standard deviation.
- Distinguishing population variance from sample variance.
- Applying Pandas groupby and aggregation operations.
- Understanding how extreme values affect statistical measures.
